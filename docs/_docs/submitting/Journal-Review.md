Journals often ask authors to give peer reviewers access to the data behind a
manuscript. If your dataset includes controlled access
human data, plan for what reviewers can and cannot see before you submit your
manuscript.

## How to set this up

If your manuscript is going to review and you want reviewers to see your
dataset's metadata, email [help@facebase.org](mailto:help@facebase.org). Please
include:

- the dataset ID or DOI
- your journal's review timeline or deadline

Your dataset still needs to go through FaceBase review before it is released.
See [Releasing Your Dataset](/docs/Dataset-Status/) for what to prepare and how
far ahead to contact us.

## Special considerations for controlled-access data

Controlled access data in any Controlled Access Data Repository (CADR),
including FaceBase, cannot be made available for anonymous review. Access to
controlled data requires an approved Data Access Request from a named
individual, so there is no way to open the data itself, or any subset of it,
to an anonymous reviewer.

### What reviewers can see

FaceBase can make **coarse metadata** about your dataset available for
anonymous review. This is the dataset's record pages, which can include:

- the dataset description and other dataset-level information
- the listing of the dataset's files, which serves as a file manifest

This lets reviewers confirm what your dataset contains and how it is organized,
without access to the controlled data files themselves.
