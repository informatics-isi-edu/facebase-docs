New datasets are initially visible only to the project to which they are
attributed. This includes all of the dataset metadata and data files that are
linked to the dataset. In order for a dataset to be "released" on the FaceBase
site, a member of the FaceBase team must review the dataset and update its
'Released' field to 'true'. Once released, the dataset will be visible to
other users of the FaceBase site.

## Plan ahead for journal deadlines

Many journals require data to be publicly available before they will formally
accept a manuscript. Release is not instant: FaceBase reviews every dataset, and
most datasets need at least one round of edits before they are ready.

**Please contact us at least two weeks before you need your
dataset released**, and let us know your deadline when you write. Starting
early leaves time to fix anything the review turns up.

## Before you request release: checklist

Make sure each of these is complete. This is not a complete list, but these are the items most often missing
when a release request comes in. Each item helps make your dataset FAIR: findable, accessible, interoperable, and reusable by other researchers and by the computational tools that increasingly depend on well-described data.

- **Dataset description.** Edit the dataset and add a full description of what
  it contains, including:
  - the type(s) of data (e.g., imaging, sequencing)
  - the number of specimens, samples, or participants
  - for human data, whether the data is open or controlled access
  - any special software, settings, or processing needed to view or use the
    files (for example, images that look dark or blank in a standard viewer)
- **A protocol for each experiment type.** Upload one protocol document for
  every experiment in your dataset. See
  [Describe Experiments and Biosamples](/docs/Describe-Experiments-and-Biosamples/)
  for instructions.
- **Files linked to biosamples.** Every data file should be linked to the
  biosample it came from. If you have many files and a consistent naming
  pattern (for example, a sample name in each file name), tell us the pattern
  and we may be able to help with the linking.
- **Review with your team.** Check the dataset and all of its metadata
  (experiments, biosample details, replicates) and data files with other
  members of your project or the PI(s).

## How to request release

Once you and your colleagues decide the dataset is ready, send an email to [help@facebase.org](mailto:help@facebase.org). Please include:

- the dataset ID or DOI
- your deadline, if you have one (for example, a journal acceptance date)
- whether you plan to add more data after release

A FaceBase curator will review your dataset and notify you either that the dataset
has been released or that it needs some additional data entry or edits by you.
