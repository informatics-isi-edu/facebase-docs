## Who is this for?

For projects [approved for adding data](https://www.facebase.org/contributing/) to FaceBase. This guide describes the submission process and how to best organize your data and the best formats to use to take advantage of system tools for visualizations and annotation.

## Why it matters

FaceBase is built around the FAIR principles, which aim to make research data
Findable, Accessible, Interoperable, and Reusable. The information you provide
when you submit, such as descriptions, standard vocabulary terms, protocols,
and biosample details, is what makes your data FAIR. It also makes your data
AI-ready: consistently described and structured so that computational tools,
not just people, can find and use it. Learn more in
[FAIR Data in FaceBase]({{ "/docs/Data-Submission-Key-Concepts/#fair-data-in-facebase" | relative_url }}).

## What you'll find

This guide will provide the following

* Key concepts for data submitters
* Timeline and overview of the data submission process.
* How data is organized in FaceBase
* How to upload data files via the web browser or using our client tools.
* Quality control rules
* How to best cite this data in your upcoming publications
* Self-guided tutorial
